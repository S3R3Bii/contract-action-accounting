# Meaning of the saved source fields

The projection contains every one of the 153 current transaction records returned for the fixed first page of 20 NASA contracts. `cases.json` retains each government award key and the current Base Obligation Date assertion. `transactions.csv` retains only government transaction keys, source calendar dates, opaque modification labels, type codes and exact signed monetary tokens, with explicit eligibility states.

These records describe one current source view. A calendar action date is not a publication timestamp. The source's Base Obligation Date assertion is not independently verified first public availability. A transaction is not automatically a distinct legal modification, staff task, paid cash transfer, loss or saving. No description, recipient name, address or contact block is included.

The capture manifest records 62 actual native response hashes and times: two identical search requests plus before/history/after requests for each contract. Agreement detects particular changes; it does not establish an atomic historical database snapshot. The native verification receipt binds the actual public projection bytes and records its independent checks. Native payloads and documentation PDFs remain private.

Amounts are `federal_action_obligation` in reported USD obligations. Negative and zero values remain visible. Missing or invalid values stay unavailable. Complete account and queue eligibility additionally requires usable identity and source-calendar coverage. No amount is converted into staff hours, official cash reporting or vendor quality.
