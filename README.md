# Count contract actions before treating dollars as administrative activity

A net obligation total can hide offsetting adjustments and zero-dollar actions. This planned audit will compare current transaction counts and signed obligations in a fixed cohort of 20 NASA contracts first obligated in 2024.

The original Study 11 pre-award prediction remains unexecuted: current transaction dates do not prove what a forecaster could have known before award. This separate retrospective accounting study measures source-record activity, not staff hours, contract quality, fraud, eligibility, vendor risk or causal impact.

Read the [fixed protocol](PROTOCOL.md), [source contract](data/source_contract.json), [data terms](DATA_RIGHTS.md) and [original source hold](SOURCE_HISTORY.md). The fixed cohort has now been captured: 20 contracts, 153 current transaction records and 62 native responses. Independent native reconciliation passes 1,768 finite conditions. Accounting and queue comparisons have not run. All source, numerical, privacy and rendered-document gates must pass before a release claim.
