# Public facts, attribution and privacy boundary

The official USAspending API makes government spending records publicly accessible. Its disclosure and federal spending guide describe research, transparency, journalism and data access uses. This package publishes a minimal factual projection and independent derived statistics, not a wholesale copy of the website, disclosure PDF, third-party expressive descriptions, federal seals or source code.

Attribution: U.S. Department of the Treasury, USAspending.gov, official API v2. Exact request URLs, capture timestamps, native hashes and current-source qualifications are retained. Treasury and the U.S. Government do not endorse this independent analysis. Source assertions can be incomplete or revised; this is not official financial reporting.

Public source fields are limited to government contract/transaction keys, dates, type and modification tokens, and signed obligation values. Full native responses, descriptions, recipient names/identifiers, contact blocks, addresses, source PDFs and raw discovery materials stay private. No assistance-to-individuals records or reidentification. Government record IDs are for traceability, not vendor or person rankings.

Original implementation code is MIT licensed. That code license does not relicense agency material or third-party expressive content. Public federal transaction facts and derived aggregate results are attributed to their source. No formal-publication manuscript, Azure project content, credential or excluded dataset is included.

Sources: [API](https://api.usaspending.gov/), [official endpoint contracts](https://github.com/fedspendingtransparency/usaspending-api), [source disclosure](https://www.usaspending.gov/data/about-the-data-download.pdf), [federal spending guide](https://www.usaspending.gov/federal-spending-guide).
